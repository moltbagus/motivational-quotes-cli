# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1.0] - 2026-05-19

### Added

- Motivational Quotes CLI with beautiful ASCII box framing
- 5 box themes: default, bold, rounded, double, minimal
- Colored output for TTY, automatic color disable for pipes
- 29 curated motivational quotes
- GitHub Actions release workflow for macOS, Ubuntu, Windows
- Homebrew formula for easy installation via `brew install`
- Go embed directive for single-binary distribution
